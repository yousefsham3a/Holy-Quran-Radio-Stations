# 📻 Quran Radio Stations

A simple and modern web project that streams live Quran radio stations from different countries, including Egypt, Saudi Arabia, and more.

---

## 🌐 Live Demo
👉 https://YOUR-LINK-HERE.netlify.app/

---

## 📌 Features

- 🎧 Live streaming of Quran radio stations
- 🔍 Search for any radio station easily
- 📱 Fully responsive design (mobile + desktop)
- 🎨 Modern UI with smooth gradients
- ▶️ Custom audio player (play / pause / mute)
- 📡 Auto-load stations from API
- ⚡ Fast and lightweight

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts
- mp3quran.net API
